# PinToDesk 系统架构与关键模块规范

本文件按需加载。涉及底层交互与系统级 API 时必须严格遵照。

## 一、Windows 低级系统钩子规范

1. **安装校验与失败退避重试**
   - 所有全局键盘/鼠标钩子（`SetWindowsHookEx`）必须具备安装结果校验与失败退避重试。
   - 通过回调极简异步化从根源防止钩子因超时被系统静默摘除，不引入后台空转轮询定时器。

2. **回调毫秒级轻量化**
   - 钩子回调内部禁止同步耗时操作或可能引起重入/死锁的逻辑。
   - 禁止在回调中直接执行 `Hide()` 或 `UnhookWindowsHookEx`。
   - 耗时业务必须使用 `Dispatcher.BeginInvoke` 异步解耦。

## 二、窗口层级、置顶与穿透联动规范

1. **穿透必置顶**
   - 开启鼠标穿透模式时，必须强制联动开启窗口置顶。
   - 杜绝下层软件点击导致界面被覆盖。

2. **取消置顶必退穿透**
   - 取消置顶状态时，必须统一且强制退出穿透模式。
   - 严禁出现“非置顶 + 鼠标穿透”导致的无法交互悬挂状态。

3. **桌面驻留免疫机制**
   - 结合 Windows 桌面 Progman 宿主从属关联（`BindOwnerToProgman`）与双阶段 Z-Order 刷新。
   - 监听 `WM_TASKBARCREATED` 在 Explorer 重启后自动重绑宿主并恢复托盘图标。
   - 确保在 `Win+D`（显示桌面）广播下依然稳定驻留桌面之上且不抢占前台焦点。

4. **全窗口自由拖动与混合 DPI 多屏规范**
   - 全窗口拖动统一调用 `NativeMethods.DragMoveWithBounds(this)`，拖动期间原生平滑跟随，松手按连通多屏工作区超界回弹（含上下错位多屏列顶边约束）。
   - 右下角缩放统一调用 `NativeMethods.AttachResizeGrip`，按物理像素工作区边界换算逻辑尺寸上限。
   - 二级窗口（待办历史、偏好设置、关于）均按需延迟实例化，关闭时 `Close()` 彻底销毁并解绑全局事件。

## 三、数据持久化与存储健壮性

1. **异步防抖与原子落盘**
   - 高频待办数据持久化必须采用异步防抖机制（300ms 防抖写盘），写入 `.tmp` 临时文件后通过 `File.Move(..., overwrite: true)` 原子替换。
   - 避免密集操作阻塞 UI 渲染线程；删除、恢复及退出时必须强制 `Flush()` 同步刷盘。

2. **读取失败熔断保护**
   - 存储层（`JsonLinesStorage` / `SettingsManager`）遭遇 IO 占用或读取失败时，必须进入保护熔断态（`HasReadFault = true`）。
   - 严禁用空数据或默认配置覆盖已有磁盘文件。
   - 提供用户可见提示弹窗，部分行损坏时保留 `.corrupt.bak` 备份。

## 四、架构变更检查清单

修改上述模块时，必须确认：

- [ ] 钩子是否有安装校验、退避重试，且回调轻量防超时摘除？
- [ ] 回调是否轻量、是否异步解耦？
- [ ] 穿透与置顶是否联动？取消置顶是否退出穿透？
- [ ] 多屏拖动与缩放是否统一收敛至 `NativeMethods` 公共辅助？
- [ ] 持久化是否防抖、原子替换、熔断、不覆盖已有数据？
