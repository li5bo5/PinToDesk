## ✨ 功能特点

- **Fluent 动态主题与磨砂质感**：支持「跟随系统（自动提取任务栏颜色与感知亮度）/ 浅色 / 深色」主题，支持 40% ~ 100% 窗口不透明度实时预览调节
- **桌面深度融合与 `Win + D` 免疫**：绑定桌面宿主 `Progman`（Explorer 重启自动重绑），非置顶状态下依然稳定常驻桌面之上，不被 `Win + D` 隐藏或遮盖
- **全局快捷键与物理遮挡探测跃居**：默认 `Ctrl + D`（可自定义）或双击托盘图标一键唤出/隐藏；被其他应用窗口遮挡时瞬间跃居最前并激活，无遮挡时一键平滑收起；唤出后点击其他窗口自然下沉
- **置顶微光与鼠标穿透联动**：点击右上角 `📌` 自由锁定置顶（顶部亮起微光指示线）；点击 `⊙` 开启鼠标穿透（强制联动置顶，移入标题栏自动临时恢复交互，移出恢复穿透）
- **统一新建与编辑体验**：双击空白处或点击右上角 `＋` 统一弹出居中编辑框；支持多行文本（`Shift + Enter` 换行）、`Enter` / `Ctrl + S` / **屏幕任意外部区域双击**快捷保存、编辑置空自动删除、Fluent 中文右键菜单
- **原生丝滑拖拽排序**：按住条目自由上下拖拽，支持平滑插槽避让动画与边缘自动滚屏
- **待办历史（回收站）**：删除待办自动归档至待办历史，支持单条原 ID 还原、彻底删除、清空历史及到期自动清理（默认保留 60 天，可自定义）
- **多显示器与混合 DPI 适配**：自由拖动跨屏零跳变，松手按连通多屏工作区超界自愈回弹；右下角拖拽缩放按物理像素严格钳制；自动记忆窗口尺寸与位置，外接显示器断开后启动自动复位
- **自研 Fluent 系统托盘与偏好设置中心**：极简 4 项托盘右键菜单（待办历史 / 偏好设置 / 关于 / 退出），二级窗口按需实例化、关闭彻底释放；单实例防多开拦截
- **绿色便携明文存储与熔断保护**：全部数据收敛于程序同级 `Data/` 目录（`.jsonl` 明文原子写盘 + 300ms 防抖异步落盘 + 读取异常熔断保护），老版本 `%AppData%\PinToDesk` 数据首次升级自动无损迁移

## 🖱️ 操作说明

| 操作 | 方法 |
|------|------|
| **新建待办** | 双击列表空白区域，或点击标题栏 `＋` 按钮 |
| **编辑待办** | 双击条目文字，或悬停条目点击右侧 `✎` 按钮（清空内容保存视为删除） |
| **保存 / 取消编辑** | `Enter`、`Ctrl + S` 或在输入框外任意位置双击保存；`Shift + Enter` 换行；`Esc` 取消 |
| **删除待办** | 鼠标悬停条目 → 点击右侧 `✕`（自动移入待办历史回收站） |
| **待办历史还原** | 右键托盘图标 → 「待办历史」→ 悬停条目点击 `⟲` 一键还原 |
| **拖拽排序** | 鼠标按住条目上下拖动，实时插槽避让并支持边缘自动滚屏 |
| **快速唤出 / 隐藏** | 全局快捷键 `Ctrl + D`（可在偏好设置自定义），或左键双击系统托盘图标 |
| **置顶 / 取消置顶** | 点击标题栏 `📌` 按钮（置顶时顶部显示微光指示线） |
| **鼠标穿透** | 点击标题栏 `⊙` 按钮（强制联动置顶，移入标题栏自动解除穿透以便操作）或于偏好设置中切换 |
| **移动与缩放窗口** | 拖动标题栏自由跨屏移动（松手自动回弹防超界）；拖拽右下角手柄调整大小（置顶时锁定） |
| **偏好设置** | 右键托盘图标 → 「偏好设置」（管理快捷键、展开/3行折叠、主题、透明度、保留天数、开机自启与布局重置） |

## 💾 数据存储（绿色便携）

v2.0 起所有数据与配置文件统一存放在程序所在目录下的 `Data/` 文件夹中，不向系统散落文件，拷贝整个文件夹即可完整迁移：

| 文件名 | 用途说明 |
| :--- | :--- |
| **`Data/settings.jsonl`** | 统一偏好配置（主题、透明度、快捷键、置顶/穿透、窗口坐标尺寸、保留天数等） |
| **`Data/todos.jsonl`** | 待办清单明文数据文件（支持原子写入与异常熔断保护） |
| **`Data/recycle_bin.jsonl`** | 待办历史（回收站）数据文件 |
| **`Data/crash.log`** | 异常崩溃诊断日志（仅在发生异常时生成） |

> 💡 **老版本平滑升级**：从 PinToDesk v1.0.x 升级时，程序首次启动会自动读取 `%AppData%\PinToDesk\todos.md` 与 `settings.json` 并无损迁移至 `Data/` 目录（原文件保留不删）。

## 🚀 开机自启动

在系统托盘图标上右键 → 「**偏好设置**」→ 勾选「**开机时自动启动 PinToDesk**」并保存即可。

> 提示：程序每次启动时会自动校准开机自启路径；若移动了 `.exe` 所在位置，运行一次新路径下的程序即可自动更新注册表路径。

## 🔧 从源码构建

```powershell
# 开发构建（门禁：0 警告 0 错误）
dotnet build PinToDesk.csproj -c Release

# 发布（独立免装版，无运行库依赖）
dotnet publish PinToDesk.csproj -c Release -r win-x64 --self-contained true -o "Publish\SelfContained_V2.0"

# 发布（框架依赖版，体积极小）
dotnet publish PinToDesk.csproj -c Release -r win-x64 --self-contained false -o "Publish\FrameworkDependent_V2.0"
```
